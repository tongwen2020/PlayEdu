# playedu-resource 资源模块概要

## 模块定位

本模块负责课程素材的资源库领域，包括资源主数据、分类关联、视频扩展信息以及上传能力。它依赖 `playedu-common`，通过公共配置和 S3 工具对接兼容 S3 的对象存储；课程模块通过资源 ID 使用本模块数据。

## 核心模型与服务

| 组成 | 职责 |
| --- | --- |
| `Resource` / `ResourceService` | 文件名称、类型、大小、路径、状态等资源主数据及分页查询 |
| `ResourceCategory` / `ResourceCategoryService` | 资源与分类的关联、重建关系和按分类查询资源 |
| `ResourceExtra` / `ResourceExtraService` | 视频时长、封面等扩展信息 |
| `UploadService` | 上传信息生成、对象存储交互和文件元数据处理 |

Mapper 接口位于 `mapper`，自定义查询位于 `src/main/resources/mapper`。API 位于应用模块的 `ResourceController`、`ResourceCategoryController` 和 `UploadController`。

## 主要流程

1. 管理端获取上传参数或分片上传 ID。
2. 客户端上传文件；大文件可使用预签名地址、分片列表和合并接口。
3. 上传完成后创建资源主记录，并按需要保存视频扩展信息。
4. 资源可关联一个或多个分类，供后台筛选和课程选材。
5. 课程课时或附件保存资源 ID，播放/下载时再读取资源信息与存储配置。

支持的具体资源类型和文件限制由上层请求校验、配置及业务常量共同约束。Spring Boot 层默认限制单文件 10 MB、单请求 15 MB；直传/分片上传路径还需结合对象存储策略核对实际限制。

## 与其他模块的边界

- `playedu-common` 提供 S3 配置、上传类型、异常、分页和工具方法。
- `playedu-course` 只保存资源引用及课时语义，不负责对象存储生命周期。
- `playedu-api` 负责上传 HTTP 协议、请求校验、权限和响应封装。
- 删除资源前，上层接口需检查课程/课时等引用，避免产生失效内容。

## 维护要点

- 数据库删除与对象存储删除并非天然原子操作，调整删除流程时需明确失败补偿策略。
- 分片上传要处理未完成分片清理、重复合并、文件唯一命名和并发请求。
- 对象存储桶、Endpoint、Access Key 和 Secret Key 必须通过安全配置提供。
- 修改资源类型或视频扩展字段时，同步检查课程课时播放逻辑和前端素材选择器。
- 本模块暂无独立测试目录，建议为上传编排、分类重建和删除引用检查补充测试。
