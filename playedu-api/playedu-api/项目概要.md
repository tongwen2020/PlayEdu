# playedu-api 应用模块概要

## 模块定位

本模块是后端唯一的可执行 Spring Boot 应用，也是所有业务模块的装配层和 HTTP 接口层。它依赖 `playedu-common`、`playedu-system`、`playedu-course`、`playedu-resource` 和 `playedu-exam`，打包后生成 `target/playedu-api.jar`。

## 启动与配置

- 启动类：`src/main/java/xyz/playedu/api/PlayeduApiApplication.java`。
- 扫描范围：`xyz.playedu` 下的组件和各模块 Mapper。
- 启用能力：事务、异步执行、定时任务和 Spring Boot 自动配置。
- 配置文件：`src/main/resources/application.yml`。
- 默认端口：`9898`。

应用配置包含 MySQL/HikariCP、MyBatis Mapper 路径、Sa-Token/JWT、上传大小、异步线程池、限流与演示模式。生产部署时应显式提供数据库密码和独立的 JWT 密钥。

## 主要代码结构

| 目录 | 职责 |
| --- | --- |
| `controller/backend` | `/backend/v1/**` 管理端接口 |
| `controller/frontend` | `/api/v1/**` 学员端接口 |
| `request/backend`、`request/frontend` | 接口入参、校验规则和批量操作模型 |
| `interceptor` | 管理端/学员端鉴权、通用 API 处理、题库方法过滤和 MVC 注册 |
| `event`、`listener` | 课程、课时、用户、部门、登录等事件及关联数据处理 |
| `bus` | 登录流程编排 |
| `cache` | 登录频率限制与登录锁定状态 |
| `schedule` | LDAP 定时同步 |
| `controller/ExceptionController.java` | 统一异常到 JSON 响应的转换 |

## API 范围

管理端接口覆盖管理员/角色/日志、应用配置、用户/部门、课程/章节/课时/附件、资源分类/资源/上传、LDAP、仪表盘、题库和试卷。学员端接口覆盖密码或 LDAP 登录、课程与分类、课时播放和心跳、学习记录、个人资料以及题目练习。

统一返回模型来自 `playedu-common` 的 `JsonResponse`。后台权限由拦截器和 `@BackendPermission` 切面共同控制；前台身份信息通过 `FCtx` 获取，后台身份信息通过 `BCtx` 获取。

## 关键流程

1. 请求先经过 `WebMvcConfig` 中配置的对应拦截器。
2. Controller 校验 Request，并调用领域 Service。
3. Service 访问数据库并返回领域对象或聚合结果。
4. Controller 使用 `JsonResponse` 输出统一响应。
5. 涉及跨模块副作用时发布 Spring 事件，由 Listener 清理缓存、关联记录或更新学习进度。

## 测试与维护

`src/test/java/xyz/playedu/api` 目前包含 `QuestionBankHttpTest` 和 `ExamPaperHttpTest`，覆盖考试中心的 HTTP 集成场景。可在父目录执行：

```bash
.\mvnw.cmd -pl playedu-api -am test
.\mvnw.cmd -pl playedu-api -am spring-boot:run
```

新增接口时应保持前后台路径分区清晰，将可复用业务规则放入领域模块，而不是堆积在 Controller；同时补齐请求校验、权限声明、操作日志与异常映射。
