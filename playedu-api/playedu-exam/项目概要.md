# playedu-exam 考试模块概要

## 模块定位

本模块提供考试中心的题库、题目、试卷、版本、练习与判分能力。它依赖 `playedu-common` 和 Spring JDBC，与其他以 MyBatis-Plus 为主的模块不同，核心 Service 直接通过 `JdbcTemplate` 执行 SQL，并使用 `Map<String, Object>` 组织查询结果。

## 核心组成

| 文件 | 职责 |
| --- | --- |
| `QuestionBankService` | 题库/分类/题目管理、版本、状态、导入导出、学员练习及历史 |
| `ExamPaperService` | 试卷分类、草稿保存、校验、发布、版本、复制、导入导出与查询 |
| `QuestionGrader` | 题目合法性校验和自动判分 |
| `QuestionBankTypes` | 题库接口输入、答案、评分规则和结果 record |
| `ExamPaperTypes` | 试卷、分区、题目项、版本和状态输入 record |
| `QuestionBankMigration` | 启动时安装题库相关表结构 |
| `ExamPaperMigration` | 启动时安装试卷相关表结构 |

## 数据模型

题库侧包含题库、题目分类、题目、题目版本、练习记录和审计表；试卷侧包含试卷分类、试卷主表、草稿分区、草稿题目项、发布版本和审计表。建表 SQL 位于 `src/main/resources/db/`。

迁移类实现 `CommandLineRunner`，按顺序在应用启动阶段执行，并将已完成项写入公共 `migrations` 表，避免重复安装。

## 业务特征

- 题目采用草稿与版本机制，支持状态切换、批量导入和导出。
- 试卷由多个分区及题目项组成，发布前先校验，再固化为不可变版本 JSON。
- 判分策略当前包含 `exact_match` 和 `manual`；自动判分由 `QuestionGrader` 完成。
- 学员端可获取开放题库、查看题目、提交练习并查询历史。
- 后台写操作会记录管理员、动作和目标对象到审计表。

## API 与测试

HTTP Controller 位于应用模块：后台为 `/backend/v1/question-bank/**` 与 `/backend/v1/exam-paper/**`，学员练习为 `/api/v1/question-bank/**`。应用模块已有 `QuestionBankHttpTest` 和 `ExamPaperHttpTest`。

在父目录执行：

```bash
.\mvnw.cmd -pl playedu-exam -am test
.\mvnw.cmd -pl playedu-api -am -Dtest=QuestionBankHttpTest,ExamPaperHttpTest test
```

## 维护要点

- 修改输入 record 时同步检查 Controller 校验、JSON 导入导出格式和已发布版本的兼容性。
- 发布版本属于历史快照，结构升级应优先考虑向后兼容，避免旧版本无法读取。
- 所有动态筛选和排序必须继续使用参数绑定或白名单，防止 SQL 注入。
- 新增表或字段需更新模块 SQL 与迁移标识，并验证全新库和已有库两种启动路径。
- `Map<String, Object>` 缺少编译期字段约束；扩展复杂返回值时可评估引入明确 DTO。
