# playedu-common 公共模块概要

## 模块定位

本模块是后端的公共领域与基础设施层，承载多个模块都会使用的组织、账号、权限、配置、LDAP、响应模型、分页模型、缓存和工具能力。它不依赖其他 PlayEdu 子模块，是 `playedu-course`、`playedu-resource`、`playedu-system` 和 `playedu-exam` 的共同基础。

## 主要业务能力

- 用户与组织：`User`、`Department`、`UserDepartment` 及相应 Service/Mapper。
- 后台账号与权限：管理员、角色、权限及多张关联表，配合后台鉴权服务。
- 登录与上下文：前后台鉴权服务、`FCtx`、`BCtx`、登录记录和上传图片记录。
- LDAP：配置模型、连接工具、用户/部门映射、同步记录及同步明细。
- 应用配置：`AppConfig`、配置常量和 `PlayEduConfig`。
- 公共基础设施：限流、内存缓存、锁、S3 工具、IP 归属地、隐私脱敏、请求与字符串工具。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `annotation` | `@BackendPermission`、`@Lock`、`@Log`，具体切面实现在 `playedu-system` |
| `bus` | 后台用户和 LDAP 的跨 Service 编排 |
| `config` | Sa-Token、MyBatis-Plus、鉴权、应用属性和 Bean 命名配置 |
| `constant` | 前后台、权限、配置、业务类型和系统常量 |
| `context` | 当前学员/管理员请求上下文 |
| `domain` | 公共领域实体 |
| `mapper` + `resources/mapper` | MyBatis-Plus Mapper 与自定义 SQL |
| `service`、`service/impl` | 领域服务接口和实现 |
| `types` | 统一响应、上传、LDAP、分页与查询结果模型 |
| `util` | 通用工具及 LDAP/S3/IP 等集成封装 |

## 数据访问与响应

领域 Service 多数继承 MyBatis-Plus `IService`，实现类继承 `ServiceImpl`；复杂统计和关联查询放在 XML Mapper 中。API 统一响应使用 `JsonResponse`，分页查询使用 `PaginationResult` 及各业务 Filter，其他模块可直接复用。

## 与其他模块的协作

- `playedu-api` 使用本模块完成鉴权、上下文读取、参数返回和用户/部门管理。
- `playedu-course` 复用用户、部门、分页结果和通用 Mapper 投影。
- `playedu-resource` 复用配置、S3 工具、分页及异常体系。
- `playedu-system` 为本模块的注解提供 AOP 实现，并初始化权限和配置数据。
- `playedu-exam` 通过 `BackendBus` 获取当前后台操作者并复用异常/响应规范。

## 维护要点

- 公共模块处在依赖底层，不应反向引用课程、资源、考试或 API 模块。
- 只有确实跨领域复用的类型和能力才应放入此处，领域专属逻辑保留在对应模块。
- 修改用户、部门、权限或配置模型时，需要同步检查 XML Mapper、系统初始化检查及上层 Controller。
- `MemoryCacheUtil`、`MemoryDistributedLock` 和内存限流适合单实例语义；扩展为多实例部署时，应评估替换为共享存储实现。
- S3、LDAP、JWT 等敏感参数应由外部配置注入，避免将生产凭据写入源码或配置默认值。
