# 试题库管理

登录 admin 后，从侧边栏「试题库」进入 `/question-bank`。

## 权限

- `question-bank-view`：显示菜单、查询题库和分类、查看试题及历史版本。直接访问页面也会校验查看权限。
- `question-bank-edit`：创建或编辑题库、管理分类、编辑或复制试题、变更状态、删除初始草稿、批量导入。
- `question-bank-export`：导出所选题库的全部试题（包括答案和解析）。

数据归属和实际操作权限由现有 API 校验。编辑与导出权限需配合查看权限使用。

## 管理流程

1. 新增题库，设置说明、启停状态与学员练习开关。
2. 在「分类管理」中建立最多三级的分类。
3. 新增单选、多选、判断或简答题，配置答案、解析、标签、难度、分值和状态。
4. 使用题干或编码、分类、题型、难度、状态、标签筛选并分页查看试题。
5. 从「详情 / 版本」查看当前内容及历史快照；每次编辑或变更状态都会生成新版本。

题库编辑携带 revision，试题编辑和状态变更携带 expectedVersion。并发修改冲突时，按接口提示刷新后重新打开编辑。归档后不可修改，可复制为新题并重新填写唯一编码。仅 v1 草稿可永久删除；只有空题库可删除。

## 导入导出

「批量导入」提供含四种题型的 JSON 模板，选择文件后会校验并展示预览，确认后整批提交。每批 1–1000 题，文件最多 20 MB。服务端事务保证整批成功或整批回滚。

支持直接读取导出生成的 JSON 数组。导入会移除题目 ID 与版本字段，改用当前题库 ID，始终作为新题创建，不覆盖旧题。编码必须在目标题库唯一；跨题库导入时需要将 categoryId 改为目标分类 ID，或 null（未分类）。文件中的状态、标准答案和解析会保留。

「导出全部试题」导出当前题库全部题目的最新版本，不受页面筛选或分页限制。服务端单次上限为 5000 题。

## 验证

```sh
npm run test:question-bank
npm run build
```

自动化用例验证四种题型、false 答案、新题导入边界、跨题库分类、重复编码、答案与评分校验、批量限制和 UTF-8 BOM。真实登录、权限分配与后端交互需在运行中的项目环境验收。
